# Weapons

`ArmingSword.glb` is generated by `Art/ArmingSword.py` with Blender 5.3, so it carries no third-party content:

```
blender.exe --background --factory-startup --python Art/ArmingSword.py -- Content/Weapons/ArmingSword.glb [preview.png]
```

It is a type XII-style arming sword in grip space: a fullered blade from the guard to the tip at 1 m, a crossguard with curled quillons, a leather grip over three risers, and a wheel pommel. `Sandbox.hlevel` names it as the player weapon, which the player and the guards hold.
