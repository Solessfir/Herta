# Droid Sans Mono

Unmodified `DroidSansMono.ttf` from the CTAN Droid 3.1 bundle: https://ctan.org/pkg/droid

Designed by Steve Matteson at Ascender for Google. The font is licensed under Apache License 2.0; see LICENSE.txt. The LaTeX support files are not included.

Output Log entries use 90% of the default editor font size, matching the 9-point log versus 10-point interface ratio. The existing per-monitor DPI and framebuffer-density scaling applies to both fonts.
